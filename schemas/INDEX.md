# Суть-схемы «Живите как хотите»

Визуальный язык (канон): белый лист · фиолетовое = **силы, что сеем** · терракота = **мотор / тайна** · зелёное = **эмерджентное, растёт само** · охра-миндалина = **взгляд игрока** · внизу пунктиром — **тайна = разрыв между тем, что движет миром, и во что верят жители**.

- [2026-07-23 — мир из встреч](2026-07-23-mir-iz-vstrech.svg) — базовая суть: люди с внутренней логикой пересекаются во встречах; игрок = случай в круге взгляда; из встреч копится летопись, толкования узора рождают идеологию. Девиз: *история = внутренняя логика × встречи*.
- [2026-07-25 — двигатель сил](2026-07-25-dvigatel-sil.svg) — машинерия опричнины: силы (страх, нужда, донос…) питают самоподдерживающийся мотор «донос → передел», из него растут эмерджентные события; внизу — тайна (верят в Бога/царя, движет страх/донос).
- [2026-07-25 — внимание и невидимый закон](2026-07-25-vnimanie-i-nevidimyj-zakon.svg) — три слоя: конус взгляда игрока (внимание = и рычаг, и бюджет ИИ) · освещённая нить одной судьбы · невидимый закон снизу; летопись в два голоса (что случилось / как назовут).
- [2026-07-26 — атом выбора](2026-07-26-atom-vybora.svg) — **ядро игры**: момент морального выбора, прожитый с двух сторон. Носитель (правитель ≡ воин, разный лишь радиус) → развилка под давлением (нет доброго, порой нет и честного) → физика власти как модификатор (структура, не приговор) → рубец/передача → установка растёт сама. Две линзы вселения: один миг изнутри правителя и изнутри воина. Девиз: *один атом — прожит с двух сторон — оттого нет простого выбора*.
- [2026-07-29 — модель души](2026-07-29-model-dushi.svg) — **карта примитивов человека**: душа = узел с двумя полюсами (НУЖДА тянет к себе / ДАР излучает от себя), рубцы искажают чтение мира, эмоция = производная поля души (датчик, не примитив). Граф душ на векторных рёбрах; зерно темперамента (~½ гены) + жизнь → характер (эмерджентный), имя = кличка-молва. Слои: КАРКАС (физика) → ЛИНЗА-сеттинг (Рай / Черниговщина) → событийный поток; явление ≠ осмысление; автономия = где живёт зло. Палитра приспособлена (терракота = нужда/тёмное, зелёное = дар). Девиз: *семя не мертвее дерева оттого, что мало*.
- [2026-08-02 — ядро: понимание как инструмент](2026-08-02-yadro-ponimanie.svg) — **петля игры**, выбранная автором: застывший кадр → улики (поступок + манера, провокация ведёт туда, где болит) → счётчик «осталось объяснений» 25→5→1 → фраза с дырами человеческими словами → **дневник** (выводы не автоматизируем — урок Her Story) и **«теперь ты можешь»**: 2–3 действия, одно открыто ТОЛЬКО пониманием. Ниже — **две линзы** (Одарка ↔ Гафія, тот же вечер с двух сторон → обе правы). В фундаменте: правду держит движок, LLM только озвучивает; генерация — для автора, не для игрока. Девиз: *понял человека — и потому смог*.
