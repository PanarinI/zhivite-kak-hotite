# Как оживить сцены (воркер-сказитель)

Без этого шага игра работает, но встречи немые (шаблонные строки, колонка преданий пуста).
С воркером каждая встреча проживается моделью: хроника + предание + память пары + редкие
имена мест. Всё — в твоём аккаунте Cloudflare, тем же путём, что ai-arena (~10 минут).

## Через дашборд (как ты уже делал 07-12)
1. **dash.cloudflare.com → Workers & Pages → Create → Worker.**
   Имя: `dolina-backend` (важно: именно так — игра уже смотрит на этот адрес). Deploy.
2. **Edit code** → вставь целиком содержимое [`worker.js`](worker.js) → **Deploy**.
3. **Settings → Variables and Secrets → Add** →
   тип **Secret**, имя `ANTHROPIC_API_KEY`, значение = твой ключ Anthropic → Save.
   (Ключ тот же, что у ai-arena — можно один на оба воркера.)
4. (Желательно) Settings → **Add binding → Rate limiting**: name `RATE_LIMITER`,
   limit `30`, period `60`. Нет такого пункта в UI — пропусти, работает и без него.
5. Готово. Открой игру и проживи день: в шапке загорится «сцены: живые».

## Если имя воркера другое
В [`../index.html`](../index.html) найди строку `const BACKEND = "https://dolina-backend...`
и впиши свой URL.

## Про деньги
Модель — `claude-haiku-4-5`, ~350 токенов на сцену, 40–90 сцен за партию → партия стоит
около цента. Rate-limit прикрывает от чужих, если файл куда-то утечёт.
