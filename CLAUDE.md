# Живите как хотите — живой контекст (Project DNA)

> Зерно проекта: само себя выращивает. Читать в начале сессии, обновлять в конце
> (шаббат). Держать маленьким и честным.

## 1. Суть (Charter) — живая гипотеза, не контракт
(«пока не знаю» — ок; пересматривается на шаббате. РАЗВОРОТ-2 07-25 вечер — см. DECISIONS.)
- Что это: игра-НАБЛЮДЕНИЕ + мягкое ВЛИЯНИЕ НА НАМЕРЕНИЯ. Открытый безвременный мир, растущий
  из ядра причудливо; развивается по эмерджентным принципам СНИЗУ (взаимодействия элементов),
  минимум/ноль хардкода. Игрок не командир и не пассивный зритель — подталкивает НАМЕРЕНИЯ,
  дальше существа живут по своей логике; ценность — чувство ОТКРЫТИЯ. (Историч. сеттинг опричнины
  пробован 07-25 и отложен — детерминирует; машинерия переносима, см. `ZERNO-MIRA.md`.)
- Зачем / цель: давняя мечта сделать игру + чистейшая оболочка оси «автономные существа живут —
  автор рядом» (та же ось, что ai-arena / living-ai / Reachy). Нерв: смотреть, как из
  взаимодействий рождается мир, и мягко клонить намерения.
- Готово, когда: цель — СОБРАТЬ и ИЗДАТЬ инди-игру (соло-потолок ~ форма Songs of Syx).
  Ближайшее ядро — спроектировать АТОМ (элемент + встреча), из него всё течёт. Дальше растить кольцами.
- Ограничения: стек автора — веб + мир-в-JSON + Cloudflare Worker (ключ там); внимание-ворота
  держат LLM-расход в центах–низких $; строить ЭВОЛЮЦИЕЙ, не рестартом.
- Не-цели: приказывать/микроменеджить (только подталкивать намерения); хардкодить явления и
  историю (сеем элементы+взаимодействия, явления возникают сами); фиксированный историч. сеттинг
  (убивает открытие); турораундная «прожить день» механика (темп непрерывный); «живой город на
  сотни голов» сразу.

## 2. Столпы (живая карта)
Позвоночник: этот файл (суть+правила) · STATE.md (где мы) · DECISIONS.md (почему; там —
свод шести законов мира, вдохнуть обязательно).
Органы: `ZERNO-MIRA.md` — ПЕРЕНОСИМАЯ машинерия из историч. эксперимента (скрытый закон · вера-у-
каждого · силы→эмерджентность · атом; сеттинг отложен, мышление применимо к любому миру) ·
`ISSLEDOVANIE-RYNKA.md` — рыночный кирпич · `schemas/` — суть-схемы.
Артефакты-прототипы: `index.html` (Долина) · `posad.html` (МВП опричнины).

## 3. Протокол роста — дыхание организма
- Вдох (старт сессии): читать этот файл → STATE → DECISIONS → нужные органы.
- Обмен веществ (всегда): любую входящую мысль направляй — устоявшееся/структурное → в столп;
  накапливающееся знание → в орган; сырое → держи в живом контексте. Всегда говори, куда положил.
- Рост: инфа повторяется и не влезает в столпы → предложи орган (имя+зачем), рождай с «да».
- Выдох (шаббат): обнови STATE; допиши «почему» в DECISIONS; поправь этот файл при смене сути/карты;
  пересмотри столпы (родить/слить/убрать); выдай «первое сообщение для новой сессии».

## 4. Законы курирования
Весь закон висит на двух: **возлюби суть** (сигнал, не лог) · **возлюби того, кого тут не было**
(пиши для следующей сессии). Производные: один факт — один дом · стабильное ≠ волатильное ·
структура по весу (YAGNI) · рост вглубь, не вширь (новый принцип вытесняет, не добавляется) ·
столпы малы — читаются на одном дыхании · имена папок/файлов/команд — латиницей · доки в git.
